## Bodega (~1280)

- Registered via `bodega-ondemand-*.json`; NOT in context until invoked.
- Invoke: `skill(name="<name>")` after router match.
- **Never** preload. Search first (`capability-scanner` / skill-router).

## Storage decision rule

- **Own** → `stow/opencode/.config/opencode/skills/`, symlink via stow.
- **Third-party unmodified** → symlink in place under `~/tools/`; never copy, never dirty their repo.
- **Third-party locally modified** → copy into stow, break the link.
- Generated (bodega manifests, node_modules, codegraph) → build outputs in place, never symlinked.
- Upstream drift: `regenerate-manifests.py --check` / `--dry-run` before write.

## Best practices

- Task matches description → load that skill; don’t reinvent.
- Creative → `brainstorming` first; multi-file feature → `feature-dev`.
- Bugs → `systematic-debugging` before proposing fixes.
- CORE is the default toolkit; WORKFLOW/DOMAIN/bodega only when needed.
