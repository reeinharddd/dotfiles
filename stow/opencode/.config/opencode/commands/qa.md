Use the connected isolated Playwright MCP for exploratory and route-aware QA. For repeatable
regression, run the project's Playwright suite or the global verifier. Check the changed surface,
guest/auth states, responsive widths, console, network failures, accessibility, focus, contrast,
and overflow. Save screenshots/traces only under `.opencode/artifacts/`.
